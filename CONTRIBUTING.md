# Contributing

For a practical introduction to editing and researching prototypes, start with the [designer guide](docs/designers/README.md). The checks below are for contributing changes to the kit itself.

Use Node 24, run npm ci, npm run check, and the root/subpath Playwright suites. Keep official GOV.UK macros instead of copying their markup. Add tests for runtime behaviour or rule validation changes. Review keyboard/screen-reader behaviour manually. Use fictional data. Document compatibility or schema changes and increment schemaVersion when stored answers become incompatible.
